First public release: Valve's NextBot/TFBot AI for Pre-Fortress 2 dedicated servers, as a Metamod:Source plugin (Windows and Linux).

### Highlights
- Bots play CTF, control points, attack/defend, KOTH, payload and payload race, arena and deathmatch maps, and hunted/VIP maps (per-map rules in `data/hunted.cfg`).
- PF2 mechanics: armor pickups, medic syringe heal/cure/infect, engineer wrench armor repair, PF2 buildings, remote pipe traps, spy disguise/cloak, hand grenades, PF2 conditions.
- Nav meshes for 163 of PF2's 164 maps (separate download), ladders from the BSPs, `pf2nb_nav_generate` for new maps.
- Optional `pf2_hunted_classrestrict` SourceMod plugin for hunted class rules.
